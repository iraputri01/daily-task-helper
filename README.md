# Daily Task Helper

Project Python sederhana yang saya buat untuk membantu mengatur tugas dan kegiatan sehari-hari.

## Kenapa saya membuat project ini?

Saya membuat project ini karena terkadang kita punya banyak tugas atau kegiatan yang harus dilakukan dan bisa bingung mau mengatur dari mana.

Dengan project ini, pengguna bisa menyimpan daftar tugas dan mengubah statusnya ketika sudah selesai.

## Fitur

- Menambahkan tugas baru
- Melihat daftar tugas
- Menghapus tugas
- Mengubah status tugas menjadi selesai
- Memasukkan pilihan melalui nomor menu
- Validasi input agar program tidak langsung error ketika memasukkan input yang salah

## Dibuat dengan

- Python

## Yang saya pelajari dari project ini

Project ini saya buat sebagai latihan untuk memahami dasar-dasar Python, seperti:

- List dan dictionary
- Function dan parameter
- `if`, `else`, dan `while`
- `for` loop
- `return`
- `try` dan `except`
- Input validation

## Catatan

Ini adalah project pertama saya dalam belajar Python. Saya berencana mengembangkan project ini sedikit demi sedikit seiring bertambahnya pemahaman saya tentang Python.
